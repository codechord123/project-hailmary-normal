# 새 학습 단원 추가하는 법 (예: 국어)

이 플랫폼은 **구조(템플릿)는 그대로**, 단원마다 **문제·컨셉만** 갈아끼우는 방식입니다.
새 단원 하나를 추가하는 절차는 아래 3단계가 전부예요.

---

## 선생님께 (비개발자)

**선생님은 코딩하실 필요 없어요.** 새 단원 문제를 **이미지(캡처)로** 보내주시면,
제가 아래 절차로 게임에 넣어 드립니다. 보내주실 때 같이 정해요:

1. 과목·단원 이름 (예: 국어 5-1 「문장의 짜임」)
2. 컨셉/주인공 (예: "단어 탐정") — 우주(수학)·수호자(사회)처럼 단원만의 세계관
3. 문제들 (객관식·OX·짝짓기 위주)

→ 레벨·에너지·상점·의상·업적 같은 **기본 기능은 모든 과목이 자동으로 공유**됩니다.

---

## 개발 절차 (3단계)

### 1) 단원 폴더 만들기
`src/content/units/_template/unit.ts` 를 복사해
`src/content/units/<새단원>/` 폴더를 만들고 내용을 채웁니다.
(미니게임 종류·문제 형식은 템플릿 주석 참고)

### 2) 등록부에 추가
`src/content/registry.ts` 의 `SUBJECTS` 에 단원을 꽂습니다.

```ts
{
  id: 'korean', name: '국어', icon: '📖',
  units: [{ kind: 'content', def: koreanUnit }],
}
```
같은 과목에 단원을 더하려면 그 과목의 `units` 배열에 한 줄만 추가하면 됩니다.

### 3) 확인
```
npm run build   # 타입·빌드 점검
npm run test    # 데이터 무결성 점검
```
끝! 로그인 → 과목 선택 화면에 새 과목/단원이 자동으로 나타납니다.

---

## 참고
- 미니게임 6종: 디펜스 · 분류 · 매칭 · OX 번개 · 보스전 · 최종보스
- 챕터마다 `mechanic` 만 정하면 해당 게임이 그 챕터 문제로 돌아갑니다.
- 문제는 통(pool)이라, 나중에 같은 챕터에 계속 추가만 하면 됩니다.
